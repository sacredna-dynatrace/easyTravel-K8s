easyTravel 소개

easyTravel은 로그인, 다양한 여행지 검색, 특가·프로모션 여행 선택, 신용카드를 이용한 여행 구매 기능을 제공하는 웹 포털입니다.

이 애플리케이션은 Dynatrace APM 제품의 기능을 보여 주기 위한 데모입니다.

iOS 앱 설치

iOS 7.1 이상에서는 이 사이트가 사용하는 자체 서명 SSL 인증서를 먼저 설치해야 합니다. SSL 인증서 링크를 눌러 내려받은 뒤 안내에 따라 설치하세요.
iOS 10.3에서는 인증서를 직접 신뢰해야 합니다: 설정 -> 일반 -> 정보 -> 인증서 신뢰 설정에서 '루트 인증서 전체 신뢰 활성화'를 켜세요.
앱 설치 후에는 설정 -> 일반 -> 프로파일 -> 구성 프로파일에서 인증서를 삭제할 수 있습니다.
마지막으로 앱을 신뢰해야 합니다: 설정 -> 일반 -> 프로파일 및 기기 관리에서 Dynatrace LLC enterprise APP을 누르고 "Dynatrace LCC" 신뢰를 선택하세요.
인증서는 자동으로 생성되며, Linux에서는 OpenSSL이 설치되어 있어야 합니다 (Windows용 OpenSSL 바이너리는 easyTravel에 포함). easyTravelLocal.properties 파일의 config.apacheWebServerSslHost 속성을 실제 주소에 맞게 설정하세요.
